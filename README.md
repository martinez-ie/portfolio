Welcome to the source code of my personal portfolio website. This site serves as an interactive showcase of my journey—bridging **12 years of B2B commercial experience** with **Data Analytics** and **Full Stack Development**.

---

## ✨ Key Features

* 🌐 **Instant Dual-Language Toggle (PT / EN):** Seamlessly switch between Portuguese and English on the fly without page reloads or external translation libraries.
* ♿ **Accessibility First (WCAG AA Compliant):** Built with strict semantic HTML5, high-contrast color pairings, visible focus states, skip-to-content links, and `prefers-reduced-motion` support.
* ⚡ **Zero-Dependency Architecture:** Pure, lightweight Vanilla HTML, CSS, and JS—delivering near-instant load speeds and top Lighthouse performance.
* 📱 **Responsive Bento-Grid Design:** Clean, editorial design inspired by modern UI trends, optimizing layout dynamically across mobile, tablet, and desktop viewports.
* 🎨 **Custom Typography & Design System:** Styled using custom CSS properties featuring Google Fonts (*Fraunces*, *Rethink Sans*, and *JetBrains Mono*).

---

## 🛠️ Tech Stack & Architecture

* **Markup:** Semantic HTML5 (`<section>`, `<article>`, `<nav>`, aria attributes)
* **Styling:** Modern CSS3 (CSS Variables, Flexbox, CSS Grid, Media Queries, Backdrop Blur)
* **Interactivity:** Vanilla JavaScript (Language toggle state, mobile drawer menu, scroll-reveal animations)
* **Hosting & Deployment:** Vercel
